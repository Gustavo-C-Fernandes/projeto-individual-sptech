# Ninho dos Dragões

Primeiro projeto individual da SPTech, que integra o conhecimento de todas as matérias do semestre.

##  Sobre o projeto
O Ninho dos Dragões é um site informativo sobre o universo do filme *Como Treinar o Seu Dragão*, feito para fãs e curiosos que querem aprofundar seus conhecimentos e testar o que sabem.

##  Funcionalidades
* Cadastro e login de usuários
* Conteúdo informativo sobre o universo (dragões, personagens, filmes e séries)
* Quiz que classifica o usuário pelo número de acertos
* Dashboard com o desempenho do usuário

##  Tecnologias utilizadas
HTML, CSS, JavaScript, Node.js, MySQL, Web Data Viz, Figma e Trello
